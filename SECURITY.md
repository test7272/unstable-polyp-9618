# Security

This repository exists to depend on as many packages as possible.
It is a demonstration, not a production system.

## Reporting a vulnerability

Do not open a public issue for security problems in this repository.
Open a GitHub Security Advisory (Repositories → Security → Advisories) or
contact the repository owner privately.

## Bot safety

- No bot in this repository merges code, deploys, publishes, or deletes.
- Dependabot/Renovate only open pull requests; humans merge them.
- All security workflows are opt-in and visible in .github/workflows.
